Project Information & Future IoT Roadmap

Problem Statement

Temperature abnormalities inside a refrigerator spoil food and cause energy inefficiency. The system detects unusual temperature patterns early.

Autoencoder Baseline

TensorFlow/Keras Deep Neural Network trained on normal temperature sequences. Predicts 10-value window reconstructions and flags anomalies via learned reconstruction error thresholds.

MOMENT Model

Open-source foundation model for time-series analysis (CMU Auton Lab) pre-trained on multi-domain time-series datasets, evaluated for zero-shot time-series anomaly detection.

Future Hardware Integration

In future physical deployment phases, an ESP32 microcontroller with a DS18B20 digital temperature sensor and piezo buzzer will transmit real-time telemetry to this Flask API.
