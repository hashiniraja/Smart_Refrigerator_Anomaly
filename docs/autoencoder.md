# Autoencoder Baseline Model Documentation

## 1. What is an Autoencoder?
An **Autoencoder** is a specialized Deep Neural Network architecture designed for unsupervised learning. Its core objective is to compress input data into a low-dimensional bottleneck representation and then reconstruct the original input from that compressed code.

## 2. Text Architecture Diagram

```text
Input Sequence (10 consecutive temperature readings)
               │
               ▼
   [ Dense Layer: 16 Units (ReLU) ]       <--- ENCODER (Compresses features)
               │
               ▼
   [ Dense Layer: 8 Units (ReLU) ]        <--- LATENT BOTTLENECK (Compact code)
               │
               ▼
   [ Dense Layer: 16 Units (ReLU) ]       <--- DECODER (Reconstructs features)
               │
               ▼
Output Sequence (10 reconstructed readings)
               │
               ▼
   [ Calculate Mean Squared Error ]        <--- RECONSTRUCTION ERROR (MSE)
               │
               ▼
  [ Compare with Threshold Line ]         <--- ANOMALY CLASSIFICATION
               │
      ┌────────┴────────┐
      ▼                 ▼
   NORMAL            ANOMALY
(Error ≤ Limit)   (Error > Limit)
```

---

## 3. Core Terminology Explained for Beginners
- **Encoder:** The initial layers of the network that reduce the input dimension from 10 features down to 8.
- **Latent Representation (Bottleneck):** The compressed 8-unit hidden layer holding essential patterns of normal temperature cycles.
- **Decoder:** The final layers that expand the bottleneck back to 10 features.
- **Reconstruction:** The output sequence generated by the Decoder.
- **Reconstruction Error:** The Mean Squared Error (MSE) between original temperature inputs and reconstructed outputs:
  $$\text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (x_i - \hat{x}_i)^2$$
- **Anomaly Threshold:** The statistical decision boundary:
  $$\text{Threshold} = \mu_{\text{train\_error}} + 3 \times \sigma_{\text{train\_error}}$$
- **Why Normal Data is Used for Training:** By training strictly on normal data, the network becomes an expert at reconstructing standard temperature patterns. When an unseen anomaly occurs, the model fails to reconstruct it accurately, producing a spike in reconstruction error!
